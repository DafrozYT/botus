# CS:GO Case Opening Website - Резюме проекта

## 📋 Описание проекта

Полнофункциональный веб-сайт для открытия кейсов CS:GO с современным дизайном, провабл фейр системой и интеграцией с market.csgo.com. Проект разработан с использованием современных технологий и готов к продакшн развертыванию.

## 🏗️ Архитектура

### Технический стек
- **Frontend**: Next.js 13+, React, TailwindCSS, Socket.IO Client
- **Backend**: Node.js, Express, Socket.IO, Passport.js
- **База данных**: MySQL 8.0
- **Кэширование**: Redis 7
- **Развертывание**: Docker, Docker Compose, Nginx

### Компоненты системы
1. **Frontend (Next.js)** - Пользовательский интерфейс
2. **Backend (Node.js)** - API и бизнес-логика
3. **MySQL** - Основная база данных
4. **Redis** - Кэширование и сессии
5. **Nginx** - Прокси-сервер и балансировщик нагрузки

## 🔐 Система безопасности

- **Steam OpenID авторизация** - Безопасная аутентификация
- **Провабл фейр** - Криптографически честная система
- **SQL Injection защита** - Параметризованные запросы
- **XSS защита** - Helmet.js middleware
- **Rate limiting** - Защита от спама
- **HTTPS** - Шифрование трафика

## 🔧 Настройка API ключей

### Steam API
1. Перейдите на https://steamcommunity.com/dev/apikey
2. Войдите в Steam аккаунт
3. Создайте API ключ
4. Добавьте в файл `.env`: `STEAM_API_KEY=your_key_here`

### Market.csgo.com API
1. Зарегистрируйтесь на https://market.csgo.com
2. Создайте API ключ в настройках
3. Добавьте в файл `.env`: `MARKET_API_KEY=your_key_here`

## 🎮 Игровая логика

### Алгоритм открытия кейсов
1. Генерация криптографического сида
2. Проверка баланса пользователя
3. Создание хеша из сида
4. Конвертация в случайное число
5. Выбор предмета по весовым коэффициентам
6. Сохранение результата в базу данных
7. Обновление инвентаря пользователя

### Система редкости
- **Consumer** (79.92%) - Обычные предметы
- **Industrial** (15.98%) - Промышленные предметы
- **Mil-Spec** (15.98%) - Армейские предметы
- **Restricted** (3.20%) - Ограниченные предметы
- **Classified** (0.64%) - Секретные предметы
- **Covert** (0.26%) - Тайные предметы
